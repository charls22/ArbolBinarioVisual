Acerca del proyecto

ArbolBinarioVisual es un proyecto educativo desarrollado para comprender las estructuras de datos y los recorridos de arboles binarios.

1. Preorden

Raiz → Izquierda → Derecha

2. Inorden

Izquierda → Raiz → Derecha

3. Postorden

Izquierda → Derecha → Raiz

Tecnologias

Java, Java Swing, HTML, CSS y JavaScript.
