# 🌳 ArbolBinarioVisual

### Sistema interactivo de recorridos de árboles binarios

**Desarrollador:** Charles Huaman Villano

## 📌 Descripción

ArbolBinarioVisual es una aplicación desarrollada en Java que permite construir y visualizar árboles binarios mediante una interfaz gráfica interactiva.

El proyecto implementa los tres recorridos fundamentales de un árbol binario: Preorden, Inorden y Postorden.

## 🚀 Características

- Construcción de árboles binarios mediante ingreso de números.
- Visualización gráfica de los nodos y sus conexiones.
- Recorrido Preorden.
- Recorrido Inorden.
- Recorrido Postorden.
- Animación visual de los nodos visitados.
- Interfaz gráfica desarrollada con Java Swing.
- Diseño moderno con colores azul oscuro.
- Pestañas para organizar las funcionalidades.
- Versión adicional de consola.

## 🛠️ Tecnologías utilizadas

- Java.
- Java Swing.
- Programación orientada a objetos.
- Estructuras de datos.
- Recursividad.

## 📂 Archivos principales

| Archivo | Descripción |
|---|---|

## ▶️ Cómo ejecutar el proyecto

1. Instalar Java JDK.
2. Abrir el proyecto en NetBeans, IntelliJ IDEA o un IDE compatible.
3. Abrir `ArbolBinarioVisual.java`.
4. Ejecutar el método `main`.
5. Ingresar los valores separados por comas.
6. Construir el árbol y seleccionar el recorrido deseado.

## 🧪 Ejemplo de entrada

50, 25, 75, 15, 35, 65, 85


## 📊 Algoritmos implementados

**Preorden:** Raíz → Izquierda → Derecha.

**Inorden:** Izquierda → Raíz → Derecha.

**Postorden:** Izquierda → Derecha → Raíz.

## 🎯 Objetivo académico

Comprender el funcionamiento de los árboles binarios, la recursividad y los diferentes métodos de recorrido mediante una aplicación interactiva.
